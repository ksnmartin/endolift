# Economics, game theory and bilevel formulations of decision-dependent demand, and their transfer to Σ_s p_s(y) Q_s(y)

Target problem throughout: min_y f'y + Σ_s p_s(y) Q_s(y), y ∈ {0,1}^n (facilities to open), p_s(y) = probability of demand scenario s given y, Q_s(y) = value of a second-stage assignment LP whose constraints depend on y (typically capacity x_ij ≤ C_i y_i).

Notation used below: "payoff-is-constant" means the quantity multiplying p_s is a fixed number (price, revenue, zone weight); "payoff-is-LP" means it is Q_s(y), an LP optimal value that itself depends on y.

---

## Key Question 1: Competitive / customer-choice facility location under random utility (Benati–Hansen, Haase, Ljubić–Moreno, Mai–Lodi). What reformulations, what structure, does it transfer?

### Takeaway
The maximum-capture problem under MNL has objective Σ_n q_n (Σ_i V_ni x_i)/(U_n + Σ_i V_ni x_i): each zone's share is a concave function of the binary vector x (via the denominator) and a monotone submodular set function, and every exact method (MILP via Li/Benati–Hansen substitution, conic, outer-approximation cuts, submodular cuts) exploits exactly one of those two properties with the per-zone weight q_n held constant. No source establishes that either property survives when q_n is replaced by a y-dependent LP value Q_s(y).

### Cited Findings
- Exact objective (binary x_i = 1 if location i opened; V_ni = e^{v_ni}; U^c_n = competitor utility mass): maximize Σ_n q_n (Σ_i V_ni x_i)/(U^c_n + Σ_i V_ni x_i). Each term −q_n U^c_n/(U^c_n + Σ_i V_ni x_i) "is concave in x", so the capture function Ψ_l(x) is concave; as a set function it "is monotonically increasing and submodular in S." — [arXiv 2403.04264v2 (survey-style treatment reproducing the Ljubić–Moreno / Mai–Lodi machinery)](https://arxiv.org/html/2403.04264v2)
- Outer-approximation (tangent) cut exploiting concavity: θ_l ≤ ∇_x Ψ_l(x̄)ᵀ(x − x̄) + Ψ_l(x̄). — [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2)
- Submodular (Nemhauser–Wolsey) cuts with marginal gain ρ_lk(S) = Ψ_l(S+k) − Ψ_l(S): θ_l ≤ Σ_k ρ_lk(x̄)(1 − x̄_k)x_k − Σ_k ρ_lk(e − e_k) x̄_k(1 − x_k) + Ψ_l(x̄), and a variant anchored at the empty set θ_l ≤ Σ_k ρ_lk(0)x_k − Σ_{k: x̄_k=1} ρ_lk(x̄ − e_k)(1 − x_k) + Ψ_l(x̄). — [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2)
- MILP via substitution (Li 1994 style, same family as Benati–Hansen): w_n = 1/(Σ_i V_ni x_i + U^c_n), s_ni = x_i w_n; bilinear s_ni linearized with bounds w^L_n, w^U_n and envelope inequalities; objective becomes Σ_n q_n Σ_i V_ni s_ni. Conic variant: objective Σ_n q_n − Σ_n q_n U^c_n w_n with r_n = Σ_i V_ni x_i + U^c_n and r_n w_n ≥ 1 (rotated cone). — [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2)
- Ljubić & Moreno (EJOR 266(1), 46–56, 2018) build the first branch-and-cut for this problem combining outer-approximation cuts and submodular cuts; "our new branch-and-cut drastically outperforms state-of-the-art exact approaches." — [ESSEC faculty page](https://faculty.essec.edu/research/outer-approximation-and-submodular-cuts-for-maximum-capture-facility-location-problems-with-random-utilities)
- Mai & Lodi (EJOR 284, 874–881, 2020): multicut outer-approximation that splits the objective into sub-functions (groups of zones, Ψ = Σ_l Ψ_l, one θ_l per group) and adds one linear cut per sub-function per iteration, motivated by "the convexity and separable structure of the objective". — [SMU repository](https://ink.library.smu.edu.sg/sis_research/5283); grouping description in [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2)
- Haase & Müller (EJOR 232(3), 689–691, 2014) compare the three linear reformulations of MNL choice probabilities in facility location (Benati & Hansen 2002 variable substitution; Haase 2009 using the MNL "constant substitution pattern"; Zhang et al. 2012 variable substitution); the Haase (2009) variant "seems to be superior". All three assume customers at a demand point are homogeneous in observables. — [IDEAS record](https://ideas.repec.org/a/eee/ejores/v232y2014i3p689-691.html); [Springer abstract of follow-up](https://link.springer.com/doi/10.1007/s40685-014-0008-6)
- Theoretical unification: any linear cut lying above Ψ_l and touching it at x̄ is a "valid cut"; the problem is equivalent to a MILP with valid cuts at every binary point; a cutting-plane method with such cuts terminates finitely (previously proved only for OA cuts). — [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2)
- Later extension with capacity/overflow penalties exists (maximum capture with random utilities and overflow penalties, UC Chile; Omega 2025 by Méndez-Vogel, Marianov, Lüer-Villagra revisiting exact row-generation methods). I did not verify their content. — [UC Chile repository](https://repositorio.uc.cl/dspace/items/e05bf1ac-f43a-4356-879d-b4ed93f8a1f9); [IDEAS Omega 2025](https://ideas.repec.org/a/eee/jomega/v136y2025ics0305048325000659.html)

### Inferences
- The objective is "payoff-is-constant": Σ_n q_n · share_n(x). Concavity in x comes from the share being an affine-over-affine ratio whose denominator is affine and positive in x; this is exactly the structure of p_s(y) when scenarios index "which facility captures the customer" under MNL. So p_s(y) itself (as a function of binary y, extended to [0,1]^n) is concave and submodular in the facility problem too — provided the attraction values do not depend on y.
- Transfer to payoff-is-LP: Σ_s p_s(y) Q_s(y) with p_s concave-nondecreasing and Q_s(y) convex-nonincreasing in y (LP value function in the RHS C_i y_i) is a product of a concave and a convex function; neither concavity nor submodularity is preserved in general. The OA cut θ ≤ ∇Ψ(x̄)(x − x̄) + Ψ(x̄) is therefore not valid for the product; the submodular cuts are not valid either unless the product set-function is itself submodular, which no cited source proves. The methods above hence replace the bilinear objective only when Q_s is independent of y (e.g., second stage is a fixed revenue per captured unit).
- Partial transfer: if Q_s(y) is bounded in an epigraph variable θ_s via Benders cuts and p_s(y) is linearized via the Li/Benati–Hansen substitution (w, s_ni), the product p_s θ_s remains bilinear (continuous × continuous). What does linearize exactly is binary × LP-value (see KQ3/KQ8 on Basciftci et al.), which suggests re-indexing scenarios so that the y-dependence of p_s factors as (binary) × (fixed number) rather than as a ratio.

### Gaps
- I did not access the full text of Ljubić & Moreno 2018, Haase & Müller 2014 or Benati & Hansen 2002; the formulations above are taken from a 2024 arXiv paper that reproduces them. The precise Benati–Hansen and Haase (2009) variable sets are not quoted.
- No source found that studies the maximum-capture objective with a y-dependent second-stage LP (capacitated assignment) and asks whether OA/submodular cuts remain valid; the capacity/overflow papers are leads only.

## Key Question 2: Assortment optimization under MNL (Talluri–van Ryzin; Rusmevichientong–Shen–Shmoys; Şen–Atamtürk–Kaminsky conic). How is Σ_j p_j(S) r_j made tractable?

### Takeaway
Revenue Σ_j r_j ν_j x_j /(ν_0 + Σ_j ν_j x_j) is a single ratio of affine functions of x (per segment); the tractable reformulations are (i) revenue-ordered enumeration (unconstrained MNL), (ii) Charnes–Cooper substitution y = 1/(ν_0 + Σ ν_j x_j), z_j = y x_j with big-M linearization, and (iii) a conic-quadratic model in which, after rewriting the objective so all coefficients are nonnegative, the only nonconvexities are 1/w and x_j/w, both representable as rotated cones y w ≥ 1 and z_j w ≥ x_j². Each relies on the per-product payoff r_j being a constant.

### Cited Findings
- Unconstrained MNL: "revenue-ordered assortments" are optimal (Talluri & van Ryzin, Management Science 50(1), 15–33, 2004, Prop. 6). Proof route (restated by a 2023 paper): adding a product raises expected revenue exactly when its price is at least the current assortment's revenue; the price-ordered set S* = {i : p_i ≥ R*} is optimal. — [arXiv 2307.13656 (Assortment Optimization with Visibility Constraints)](https://arxiv.org/pdf/2307.13656); revenue-ordering can fail outside MNL (two-product counterexample under sequential MNL, ratio ≈ 89.3%) — [arXiv 1707.02572](https://arxiv.org/pdf/1707.02572); tight bounds under general "regular" choice models — [arXiv 1606.01371](https://ar5iv.labs.arxiv.org/html/1606.01371)
- Capacity-constrained MNL: Rusmevichientong, Shen & Shmoys, "Sum-of-ratios optimization with a capacity constraint", Operations Research Letters (2009) — listed in Shmoys' annual report; content not accessed. — [Cornell CS report](https://www.cs.cornell.edu/annual_report/2009/Shmoys.08-09.pdf)
- Mixed-MNL constrained assortment (CAOP): max Σ_i γ_i [Σ_j ρ_ij ν_ij x_j /(ν_i0 + Σ_j ν_ij x_j)] s.t. Σ_j β_kj x_j ≤ κ_k, x ∈ {0,1}^N. Traditional MILP: let y_i = 1/(ν_i0 + Σ_j ν_ij x_j), giving bilinear max Σ_ij γ_i ρ_ij ν_ij y_i x_j s.t. ν_i0 y_i + Σ_j ν_ij y_i x_j = 1; then z_ij = y_i x_j linearized with big-M U = 1/ν_i0: ν_i0(y_i − z_ij) ≤ 1 − x_j, 0 ≤ z_ij ≤ y_i, ν_i0 z_ij ≤ x_j. "formulation (MILP) does not scale well... when the capacity constraints are tight". — [Şen, Atamtürk, Kaminsky, arXiv 1705.09040 (Operations Research 66(4), 994–1003, 2018)](https://arxiv.org/pdf/1705.09040)
- Conic formulation: with ρ_i = max_j ρ_ij, rewrite objective as Σ_i γ_i ρ_i − Σ_i γ_i [ν_i0 ρ_i + Σ_j ν_ij(ρ_i − ρ_ij)x_j]/(ν_i0 + Σ_j ν_ij x_j), so the problem becomes min Σ_i γ_i ν_i0 ρ_i y_i + Σ_ij γ_i ν_ij(ρ_i − ρ_ij) z_ij with "since the objective coefficients are nonnegative, it suffices to use only lower bounds on y and z": z_ij ≥ y_i x_j, y_i ≥ 1/(ν_i0 + Σ_j ν_ij x_j). With w_i = ν_i0 + Σ_j ν_ij x_j these become rotated cones y_i w_i ≥ 1 and (using x_j = x_j²) z_ij w_i ≥ x_j². Redundant-for-integer but relaxation-strengthening cut ν_i0 y_i + Σ_j ν_ij z_ij ≥ 1 is facet-defining (Prop. 1). — [arXiv 1705.09040](https://arxiv.org/pdf/1705.09040)
- McCormick estimators on z_ij = y_i x_j using global and conditional bounds on y_i derived from the capacity constraints (Props. 2–4); CONIC+MC dominates MILP+MC; root gap drops to 0.10% on average, some instances >100× faster. — [arXiv 1705.09040](https://arxiv.org/pdf/1705.09040)
- Sales-based LP (Gallego, Ratliff, Shebalov, OR 63(1), 212–232, 2015): change decision variables from offer sets to sales quantities x_lk (k = 0 is no-purchase). Formulation: max Σ_l Σ_k p_lk x_lk s.t. capacity Σ_l Σ_k A_lk x_lk ≤ c; balance (ṽ_l0/v_l0) x_l0 + Σ_k (ṽ_lk/v_lk) x_lk = D_l; scale x_lk/v_lk − x_l0/v_l0 ≤ 0; x ≥ 0. Theorem 2: equals the choice-based deterministic LP value under the general attraction model. "A major advantage of the SBLP formulation is that it neatly avoids the usual non-linearities associated with calculating dependent demands". — [Columbia working paper](https://business.columbia.edu/sites/default/files-efs/imce-uploads/CPRM/2011-4-GAMplusSBLPv8.pdf); [IDEAS record](https://ideas.repec.org/a/inm/oropre/v63y2015i1p212-232.html)

### Inferences
- Change of variables catalogue for the ratio form: (a) y = 1/denominator (Charnes–Cooper; exact after big-M or McCormick because x is binary); (b) conic: same y plus the sign trick (subtract from the max price so coefficients are ≥ 0) so that only the convex side 1/w and x/w is needed — convexity of 1/w on w > 0 is the structural property; (c) SBLP: optimize over induced sales x_lk directly; the balance/scale constraints are the polyhedral description of achievable sales vectors under the attraction model when offer sets may be mixed over time.
- Transfer to Σ_s p_s(y) Q_s(y): the conic trick requires the numerator coefficient of each scenario to be a constant ρ_ij so that the sign-shift makes every term a nonnegative multiple of a convex 1/w or x/w. If ρ_ij is replaced by Q_s(y), the term Q_s(y)/w(y) is a ratio of a convex LP value to an affine function, which is not convex in general; the rotated-cone representation fails. The SBLP analogue would be to optimize over the induced demand vector d (captured demand per zone) with balance/scale constraints and then feed d into the recourse LP: the recourse is then linear in (d, x_s), but the link d ↔ y is exact only when the polytope's vertices correspond to integer open sets, which the SBLP guarantees only for "open/closed" sales decisions in a fluid model, not for a binary y with a fixed-charge first stage (see KQ7).
- The uncapacitated MNL case is the only one where a closed form (revenue ordering) removes the bilinearity entirely; it works because the per-product payoff is a constant threshold comparison — there is no analogous ordering when the payoff is Q_s(y).

- Did not access Talluri & van Ryzin 2004 or Rusmevichientong et al. 2009 directly; their results are reported via citing papers.
- Did not find any paper applying the Şen–Atamtürk conic trick to a problem where the per-item payoff is itself an LP value.

## Key Question 3: Bilevel / MPEC formulations with demand as a lower-level optimum; KKT / strong-duality collapses; stochastic bilevel (Beck–Ljubić–Schmidt 2023; Kleinert et al. 2021)

### Takeaway
Stochastic bilevel problems are written as min_x E_ω[F(x, y(x,ω))] with y(x,ω) solving a lower-level problem (or VI) parameterized by x and ω; with a finite scenario set and a wait-and-see follower they reduce to a deterministic bilevel problem with one follower block per scenario, which is then collapsed by KKT (with big-M/SOS1 complementarity) or by LP strong duality. Convexity of the resulting single-level objective holds only when the leader's objective depends on the lower-level optimal value alone — not on the follower's decision — and decision-dependent probability distributions in bilevel are explicitly flagged as "another completely open field of research".

### Cited Findings
- Deterministic generalized bilevel: min_{x∈X} F(x,y) s.t. −T(x,y) ∈ N_{Y(x)}(y) (lower level is a VI; equals the classic bilevel when T = ∇_y f and f pseudo-convex). Risk-neutral stochastic counterpart (Patriksson & Wynter 1999): min_{x∈X} E_ω[F(x, y(ω))] with y(ω) ∈ {y : −T(x,ω,y) ∈ N_{Y(x,ω)}(y)}; timing: leader here-and-now, uncertainty realizes, follower wait-and-see. Theory covers "existence of solutions as well as convexity and directional differentiability of the (implicitly defined) upper-level objective function". — [Beck, Ljubić, Schmidt, survey preprint (EJOR 311(2), 401–426, 2023)](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Convexity condition (Wynter 2008 handbook chapter as reported): "Convexity, however, is only possible if the upper-level problem does not contain any coupling constraints and if the objective function of the upper level only depends on the optimal value of the lower level and not on the follower's decision itself." — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Deterministic equivalent: "for a risk-neutral here-and-now follower and with a given set of discrete scenarios, one can easily turn bilevel two-stage stochastic optimization problems into their bilevel deterministic counterparts"; Henkel (2014) studies "both the classic KKT as well as the optimal-value reformulation for stochastic bilevel problems with discrete and finite probability distributions"; Bolusani et al. (2020) exploit block-angular structure with Benders-like decomposition (MibS). — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Applied energy/pricing papers collapse the lower level by "KKT approach with big-M reformulations à la Fortuny-Amat and McCarl (1981)" or "via strong duality" with finite scenarios; "nonlinear KKT complementarity" handled with binaries or SOS-1. — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Facility-location instance of stochastic (pessimistic) bilevel: Yanıkoğlu & Kuhn (2018) — leader binary here-and-now, follower continuous LP after uncertainty; min_x sup c_x'x + E_ω[c_y(ω)'y(ω)], y(ω) ∈ argmin{d(ω)'y' : Ay' ≤ b(x,ω)}; primal and dual decision rules give bounding MILPs "not significantly harder than the nominal variant"; applied to facility location with up to 35 locations. — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Decision-dependent distributions inside bilevel: Jia, Wan et al. (2011) treat the follower's cooperation level as "a decision-dependent random function β(x)"; Salas & Svensson (2020) let each leader hold a belief β^i(x), "a decision-dependent probability distribution", and optimize expected values (existence results only). Zhang, Liu et al. (2022): leaders' here-and-now decision "influences the description of the uncertainty set" (worst-case approach). Survey conclusion (ix): "only a few papers ... started to pave the way for the study of decision-dependent uncertainties. This is, however, another completely open field of research." — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Survey conclusion (iv): "The literature on stochastic bilevel optimization is rather theoretical... almost all use the deterministic equivalent as the main algorithmic workhorse." — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Kleinert, Labbé, Ljubić, Schmidt, "A Survey on Mixed-Integer Programming Techniques in Bilevel Optimization", EURO J. Comput. Optim. 9 (2021) 100007: covers convex/linear and mixed-integer lower levels, pricing, Stackelberg and interdiction; >250 references. — [ESSEC record](https://faculty.essec.edu/research/13242-a-survey-on-mixed-integer-programming-techniques-in-bilevel-optimization). General single-level routes: KKT → MPCC; Wolfe/Mond-Weir duality-based reformulations; caveat that "all these reformulations suffer from the appearance of so-called implicit variables" so local optima may not correspond. — [arXiv 2512.03376 (seven single-level reformulations compared)](https://arxiv.org/html/2512.03376v1)

### Inferences
- In the target problem, the "follower" is the assignment LP, so writing Q_s(y) via its dual (strong duality) is the standard collapse: Q_s(y) = max_{π,υ}{π'b_s + Σ_i C_i y_i υ_i : dual feasible}. Multiplying by p_s(y) then gives products p_s(y)·y_i·υ_is — continuous dual × binary (× p_s). When p_s(y) is affine in y this is "dual × binary × binary", exactly linearizable by McCormick (this is Basciftci–Ahmed–Shen's route, KQ8). When p_s(y) is a logit ratio, one gets dual × binary × (1/denominator), which needs the extra Charnes–Cooper variable from KQ2 and is no longer exactly linearizable without further branching.
- The Wynter convexity condition is informative for the target problem: the leader's objective Σ_s p_s(y) Q_s(y) depends on the lower-level optimal value only (good), but the weights p_s(y) depend on y (bad): the convexity results in the survey assume fixed scenario probabilities, so even the continuous relaxation in y is not covered.
- Stochastic bilevel with decision-dependent distributions is explicitly open; no cited work reformulates "E_{ω∼P(x)} [value function]" into a convex program.

- Did not access Kleinert et al. 2021 full text; whether it discusses products of value functions with first-stage-dependent weights is unknown.
- Salas & Svensson 2020 and Jia et al. 2011 were not read; only existence results are reported by the survey.

## Key Question 4: Variational inequality / Nash equilibrium formulations where demand is an equilibrium; is the equilibrium map monotone in y?

### Takeaway
Equilibrium-constrained location problems are written as (S)MPECs with the lower level a VI −T(x,y) ∈ N_{Y(x)}(y) (traffic/Wardrop user equilibrium is the archetype); the recent congested-facility-location work with M/M/c queues under user equilibrium reports a single-level convex MINLP reformulation. No source found states monotonicity of the equilibrium demand map in the facility vector y, and the SMPEC theory only yields directional differentiability of the implicit objective, not convexity.

### Cited Findings
- SMPEC definition and theory (Patriksson & Wynter 1997, 1999): VI lower level T(x,y*)'(y − y*) ≥ 0 ∀y ∈ Y(x); traffic equilibrium with uncertain travel demand as motivating example; descent methods using sensitivity analysis; later Patriksson (2008) shows "SMPEC solutions continuously depend on the probability distribution". — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- Congested facility location under user equilibrium (Sugishita, HEC Montréal, GERAD seminar April 8, 2026): facilities as M/M/c queues; users choose a facility minimizing travel + waiting time; upper level chooses facility configuration; "a flexible single-level reformulation" that is "a convex mixed-integer nonlinear program that can be solved efficiently" and accommodates efficiency and fairness objectives. — [GERAD seminar page](https://www.gerad.ca/en/events/2425)
- Marcotte (2016 talk): stochastic competitive location with queueing where users reach a stochastic equilibrium; mixed-integer linear reformulation; heuristic giving users full control "can be arbitrarily poor in the worst case". — reported in search summary; original page not fetched ([GERAD events list](https://www.gerad.ca/en/events/2425) is the only verified GERAD link)
- Bilevel VI / optimal Nash-equilibrium seeking with Wardrop benchmark (Nguyen–Dupuis network). — [arXiv 2307.12511](https://arxiv.org/pdf/2307.12511)
- Beck et al. survey lists Wynter-type results: "sufficient conditions that ensure that the upper-level objective function is Lipschitz continuous and directionally differentiable" (not convex). — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)

### Inferences
- For a user-equilibrium lower level, the equilibrium is the minimizer of a convex potential (Beckmann-type) when costs are separable and monotone; a convex-MINLP single-level reformulation (as Sugishita reports) presumably arises because the potential can be written jointly in (y, flows). That gives convexity in the flows for fixed y, not concavity/convexity of the induced demand in y. Monotonicity of the equilibrium map in y (more facilities → more demand captured, in a VI-monotone sense) was not found in any source.
- For the target problem the lesson is that equilibrium formulations trade the explicit p_s(y) for an implicit solution map; this only helps if the resulting leader objective is a value function (then convex in RHS-type parameters) rather than a product of a probability and a value function.

### Gaps
- No peer-reviewed paper found for the Sugishita reformulation (seminar abstract only); exact formulation unknown.
- No source found establishing monotone (in y) equilibrium demand maps for facility location; Geunes & Konur (2012, Transportation Research E) and Dafermos (1980) were surfaced by search but not read.

## Key Question 5: Mechanism design / revelation principle — menus of distributions and the LP approach (Vohra 2011)

### Takeaway
Vohra's monograph presents mechanism design as linear programming over allocation/transfer variables indexed by reported types, with incentive compatibility as linear constraints; the search produced only bibliographic descriptions, so the specific "menu of distributions" linearization could not be documented from sources. Whether the planner's problem Σ_s p_s(y) Q_s(y) admits a "menu" variable that makes it linear is therefore stated below only as an inference.

### Cited Findings
- Vohra, Mechanism Design: A Linear Programming Approach (Econometric Society Monographs 47, Cambridge UP, 2011): chapters on Arrow's theorem, network flow problems, incentive compatibility, efficiency, revenue maximization, rationalizability; "a linear-programming account of the underlying mathematics of mechanism design" claimed to be "elementary and transparent" and to unify results. — [UPenn Economics record](https://economics.sas.upenn.edu/node/13859); [library record with contents](https://library.nlumeg.ac.in/bib/9009)
- Vohra, "Optimization and Mechanism Design", Mathematical Programming 134, 283–303, 2012 (citation confirmed in CV only). — [Vohra CV](https://pikprofessors.upenn.edu/sites/default/files/2021-10/vohra-cv.pdf)
- Grossman & Hart (1983) abstract: when the agent's preferences over income lotteries are independent of action, "the cheapest way to implement a given action can be found by solving a convex programming problem" (relevant because this is the "menu" structure: enumerate actions = enumerate distributions, solve a convex program each). — [Econometric Society record](https://www.econometricsociety.org/publications/econometrica/1983/01/01/analysis-principal-agent-problem)

### Inferences
- The mechanism-design LP is linear because the planner's variables are the allocation and transfer for each reported type and the distribution over types is exogenous; the agent's choice of report is what is "endogenous", and the revelation principle removes it by adding one linear IC constraint per (type, misreport) pair. In the facility problem the "distribution" is chosen by the planner, not by an agent with private information, so the revelation principle has no direct analogue: there is no private type over which to take expectations with fixed weights.
- The closest analogue is "menu of distributions = enumerate y" (as in Grossman–Hart Step 2): define λ_y ∈ {0,1} for each candidate open set y; then Σ_y λ_y Σ_s p_s(y) Q_s(y) is linear in λ with Q_s(y) precomputed — linear but with exponentially many menu entries, i.e., it is full enumeration with an LP per entry. This is exactly what the catalogue is trying to avoid; LP-based mechanism design does not reduce the enumeration, it only organizes it.
- A Dantzig–Wolfe/column-generation view of that menu (λ_y ≥ 0, Σ λ_y = 1) would give the convex hull of the points (y, Σ_s p_s(y)Q_s(y)); pricing a column means solving the original nonconvex problem for one y, so no tractability is gained unless the pricing problem has structure (e.g., submodularity as in KQ1 when Q_s is constant).

### Gaps
- No readable text of Vohra 2011/2012 was obtained; the role of the revelation principle in collapsing endogenous distributions to linear constraints is stated from general knowledge, not from a fetched source.
- No paper found that applies a "menu of distributions"/LP-mechanism-design formulation to decision-dependent stochastic programming.

## Key Question 6: Principal–agent / moral hazard: Σ_s p_s(a) u_s bilinear in action and payoff; first-order approach (Mirrlees, Rogerson 1985, Jewitt 1988); Grossman–Hart's enumerate-actions + convex program

### Takeaway
Grossman–Hart handle the bilinearity between the action-controlled distribution p(·|a) and the payoff vector by a two-step scheme — for each fixed action solve a convex program in the payoff variables (linear in utilities), then enumerate actions — which is literally "enumerate distributions, solve a convex program per distribution"; they do not avoid enumeration (the action set is finite). The first-order approach avoids enumeration for a continuous action but is valid only under MLRP plus the convexity-of-distribution-function condition (CDFC), which make the agent's expected utility concave in the action. These conditions constrain how the distribution varies with the action, and they have no established analogue for a binary facility vector.

### Cited Findings
- Principal–agent problem: principal chooses action a and contract w to maximize U(w,a) s.t. participation V(w,a) ≥ V̄ and IC a ∈ argmax V(w,â); the first-order approach "replaces (2) with the first-order condition V_a(w,a) = 0", which "is only a necessary condition"; Mirrlees first showed it "was not generally valid"; Rogerson (1985) and Jewitt (1988) give sufficient conditions. — [Wikipedia: First-order approach](https://en.wikipedia.org/wiki/First-order_approach)
- Rogerson (Econometrica 1985): the two sufficient conditions are "the monotone likelihood ratio condition and convexity of the distribution function condition". — [Econometric Society record](https://www.econometricsociety.org/publications/econometrica/1985/11/01/first-order-approach-principal-agent-problems); Jewitt (Econometrica 1988) argues the Mirrlees–Rogerson conditions break down with more than one statistic and that the convexity assumption "is too restrictive for many standard distributions". — [Econometric Society record](https://www.econometricsociety.org/publications/econometrica/1988/09/01/justifying-first-order-approach-principal-agent-problems); later information-space conditions (JET 2015). — [IDEAS](https://ideas.repec.org/a/eee/jetheo/v160y2015icp243-279.html)
- Grossman & Hart (Econometrica 51(1), 7–45, 1983): the FOC-based approach "is generally invalid because of a result by Mirrlees"; alternative: if the agent's preferences over income lotteries do not depend on action, "the cheapest way to implement a given action can be found by solving a convex programming problem", used to characterize the optimal incentive scheme. — [Econometric Society record](https://www.econometricsociety.org/publications/econometrica/1983/01/01/analysis-principal-agent-problem); [IDEAS](https://ideas.repec.org/a/ecm/emetrp/v51y1983i1p7-45.html)
- Two-step procedure as taught (Georgiadis, Northwestern Ec 515 Module 5): "1. Fix the action a to implement, and find the optimal wage schedule w(·). 2. Choose the optimal action a*." Step 1 for fixed a: min over w(·) of ∫[w(q) − λ(u(w(q)) − c(a) − ū)] f(q|a) dq, maximized pointwise; "Maximization problem is concave." Step 2: max_a E[q|a] − u^{-1}(ū + c(a)). With moral hazard: "1. Find cheapest wage schedule w(q) to implement a. 2. Find 'best' action subject to (IC) and (IR)." — [Georgiadis lecture notes](https://www.kellogg.northwestern.edu/faculty/georgiadis/Teaching/Ec515_Module5.pdf)
- MLR as stated: f(q|L)/f(q|H) "decreases in q"; implies the optimal wage w(q) increases in q. CDFC as stated: "Suppose F(q|a) is convex in a"; then by integration by parts V(a) = u(w(q̄)) − ∫ u'(w(q)) w'(q) F(q|a) dq − c(a), which is concave in a when w' ≥ 0 (from MLR) and F convex in a — so the agent's problem has a global maximum at the FOC. Counterexample to the FOA without these: Mirrlees (via Bolton–Dewatripont). — [Georgiadis lecture notes](https://www.kellogg.northwestern.edu/faculty/georgiadis/Teaching/Ec515_Module5.pdf)

### Inferences
- Change of variables in Step 1 (from the convex-program statement): the principal's cost for fixed a is Σ_s p_s(a) w_s, and IC/IR are Σ_s p_s(a) u(w_s) − c(a) ≥ Σ_s p_s(a') u(w_s) − c(a') and ≥ ū. Optimizing over utilities v_s = u(w_s) instead of wages makes IC/IR linear in v (fixed coefficients p_s(a), p_s(a')) and the objective Σ_s p_s(a) u^{-1}(v_s) convex (u concave ⇒ u^{-1} convex). This is why the per-action program is convex: the bilinearity p_s(a)·v_s is broken by fixing a. The action enters only through the coefficient vector p(·|a), so enumeration over a is unavoidable in their framework; nothing in Grossman–Hart reduces the number of actions to try.
- Mapping to facility location: a ↔ y, w_s ↔ the recourse decision in scenario s, u(w_s) ↔ −Q_s. Step 1 (fix y, solve the recourse) is trivial in the facility problem (it is an LP per scenario). The economics literature's extra content is only in Step 2 and in the FOA. The FOA replaces enumeration over a by the agent's FOC — i.e., it uses that the agent (not the principal) chooses a, and that the agent's objective Σ_s p_s(a) v_s − c(a) is concave in a under MLRP+CDFC. In the facility problem the planner chooses y directly, so the FOA is not an IC-relaxation but just "relax y to continuous and use first-order conditions"; validity would require Σ_s p_s(y) Q_s(y) to be convex in y on [0,1]^n (CDFC-like: cumulative scenario probability convex in y, plus a monotone ordering of Q_s across scenarios playing the role of w'(q) ≥ 0). With Q_s(y) itself varying in y this ordering is not given, and even with it, the integer restriction remains.
- Concretely, a CDFC analogue: if scenarios can be totally ordered s = 1..S so that Q_1(y) ≥ Q_2(y) ≥ ... for all y (bad-to-good) and the cumulative F_s(y) = Σ_{t≤s} p_t(y) is convex in each y_i (each facility shifts mass toward good scenarios at a decreasing rate), then Σ_s p_s(y) Q_s = Q_S + Σ_{s<S} F_s(y)(Q_s − Q_{s+1}) would be convex in y when Q_s are constants (Abel summation; nonneg differences times convex F_s). With Q_s(y) y-dependent and convex, the product F_s(y)(Q_s(y) − Q_{s+1}(y)) is again a product of convex functions, which is not convex in general. This is my derivation, not a sourced result.

### Gaps
- Grossman & Hart's full text (and the exact statement that utilities are the choice variables) not accessed; the convex-program claim is from the abstract.
- Jewitt's alternative conditions (which replace CDFC by conditions on the likelihood ratio and the utility function) were not retrieved in detail.

## Key Question 7: Decision-dependent demand in revenue management (Gallego & van Ryzin 1994): optimizing over the demand rate instead of the price; would optimizing over induced probabilities instead of y make sense for facility location?

### Takeaway
Gallego–van Ryzin assume a "regular" demand function λ(p) with inverse p(λ) and a revenue rate r(λ) = λ p(λ) that is concave in λ; they state explicitly that one can "view the intensity λ as the decision variable", and the deterministic problem max ∫ r(λ(s)) ds s.t. ∫ λ(s) ds ≤ n is a convex program that upper-bounds the stochastic optimum. The transfer to facility location requires an invertible, convexity-preserving map from decisions to induced demand; with binary y the image is a finite set, so the analogous relaxation optimizes over the convex hull of induced demand vectors, which corresponds to randomized location decisions and gives only a bound unless the optimum is at a vertex.

### Cited Findings
- Modeling assumption: "there is a one-to-one correspondence between prices and demand rates so that λ(p) has an inverse, denoted p(λ). One can therefore alternatively view the intensity λ as the decision variable; the firm determines a target sales intensity λ (i.e., an output quantity) and the market determines the price p(λ)... From an analytical perspective, the intensity is more convenient to work with." Revenue rate r(λ) = λ p(λ) (eq. 1) "satisfies lim_{λ→0} r(λ) = 0, is continuous, bounded and concave, and has a bounded least maximizer"; "Concavity of r(λ) stems from the standard economic assumption that marginal revenue is decreasing in output." Such λ(p) is called a regular demand function; example: exponential λ(p) = a e^{−αp} gives r(λ) = (λ/α) log(a/λ). The demand seen by a firm facing competitors "may be modeled using a multinomial logit" but competition is not modeled explicitly. — [Gallego & van Ryzin, Management Science 40(8), 999–1020, 1994 (Columbia PDF)](https://business.columbia.edu/sites/default/files-efs/pubfiles/3943/vanryzin_optimal_dynamic_pricing.pdf)
- Deterministic bound (Theorem 2): J*(n,t) ≤ J^D(n,t), where J^D(n,t) = max_{λ(s)∈Λ} ∫_0^t r(λ(s)) ds s.t. ∫_0^t λ(s) ds ≤ n; "Since this is a convex program ... there exists a multiplier λ* for which the duality gap is zero"; proof uses the augmented functional ∫(r(λ_s) − μλ_s) ds + nμ. Solution: λ^D = min{λ*, λ⁰} with λ⁰ = n/t the run-out rate; fixed-price heuristics are asymptotically optimal. — [Gallego & van Ryzin 1994](https://business.columbia.edu/sites/default/files-efs/pubfiles/3943/vanryzin_optimal_dynamic_pricing.pdf)
- Later literature states the fluid model in demand-rate variables with r(x) := xᵀ f^{-1}(x) assumed strictly concave. — [arXiv 2009.02861](https://arxiv.org/pdf/2009.02861)
- SBLP (KQ2) is the discrete-choice analogue of the same change of variables: decision variables are sales quantities, with balance and scale constraints replacing the offer-set variables, and the LP is equivalent to the choice-based LP. — [Columbia SBLP paper](https://business.columbia.edu/sites/default/files-efs/imce-uploads/CPRM/2011-4-GAMplusSBLPv8.pdf)

### Inferences
- The change of variables works in GvR because (i) p ↦ λ is a bijection on a continuum, (ii) the objective expressed in λ is concave, and (iii) the constraint (inventory) is linear in λ. In the facility problem, (i) fails: y ∈ {0,1}^n maps to finitely many probability vectors p(y); (iii) partially holds: if Q_s depends on y only through capacity C_i y_i, the recourse constraints are linear in y, not in p; one would need y as a function of p, i.e., invertibility.
- A faithful analogue is to introduce the induced demand/probability vector as an explicit variable π with linear "balance/scale" constraints linking π to y (as SBLP does with x_lk ≤ v_lk x_l0/v_l0 and the balance hyperplane), so that the objective becomes Σ_s π_s Q_s(y) — still bilinear (π continuous × LP value in y) unless Q_s is constant. The SBLP sidesteps this only because its payoff is a fixed price p_lk. So the "intensity control" trick removes the nonlinearity of p(y) but not the product with a y-dependent recourse value.
- Where it does help: if the recourse depends on y only through the captured demand (e.g., Q_s depends on π but not directly on y — the facility capacity is not binding or is embedded in π), then the problem in π is a (convex) LP over the polytope of achievable π, and the only remaining task is to find an integer y realizing π*; the GvR/SBLP results suggest the LP optimum may be a vertex of the achievable-π polytope, but whether vertices correspond to integer y in a capacitated fixed-charge setting is not established by any source found.

### Gaps
- No source found that applies an intensity-control/sales-based change of variables to facility location with a capacitated second stage.
- The GvR "null price" convention (λ = 0 when stock-out) is what makes the deterministic problem interior; the facility analogue (a "no-service" scenario absorbing demand) was not studied in the sources.

## Key Question 8: Stochastic programming with decision-dependent probabilities (Hellemo–Barton–Tomasgard 2018; Medal–Affar 2024; Basciftci–Ahmed–Shen 2021; DRO with decision-dependent ambiguity) — how do OR papers write p_s(y) and what do they do with the bilinearity?

### Takeaway
The OR literature writes p_s(x) either as an affine distortion of a prior, a convex combination of fixed distributions with first-stage weights, a product of per-component probabilities Π_i Σ_ℓ f_i(ξ_i^s;ℓ) x_iℓ (multilinear), or via moments that are (piecewise) linear in y; in every case the deterministic equivalent is multilinear and is handled by McCormick envelopes (exact at binary points but with weak LP relaxations), global solvers (BARON), successive refinement of the scenario partition, or — for DRO with moment sets — strong duality on the inner problem followed by McCormick on dual × binary products.

### Cited Findings
- Hellemo, Barton, Tomasgard (Computational Management Science 15, 369–395, 2018): "Stochastic programming with recourse usually assumes uncertainty to be exogenous"; presents a taxonomy of recourse models with decision-dependent uncertainty and three ways to link decisions to probabilities: "prior probabilities are distorted through an affine transformation or combined using a convex combination of several probability distributions"; "parameters of the probability distribution are first-stage decision variables"; distributions "either incorporated using the exact expression or a rational approximation"; instances solved with BARON "using selective branching". — [MIT DSpace record](https://dspace.mit.edu/handle/1721.1/117361); [IDEAS record](https://ideas.repec.org/a/spr/comgts/v15y2018i3d10.1007_s10287-018-0330-0.html)
- Medal & Affar (arXiv 2409.08403, 2024), two-stage SP with decision-dependent random capacities: P[ξ | x] = Π_{i∈I} Σ_{ℓ=0}^{L} f_i(ξ_i; ℓ) x_iℓ with binary allocation-level variables x_iℓ (eq. 4); deterministic equivalent (eq. 5): min c'x + Σ_{s=1}^{S} (Π_i Σ_ℓ f_i(ξ_i^s;ℓ) x_iℓ) q'y_s s.t. W y_s = b, y_is ≤ u_i ξ_i^s, y_s ≥ 0. "Linearizing this with binary first-stage vectors still requires many added constraints and auxiliary variables to iteratively form McCormick envelopes. While these envelopes are exact for binary solutions, the linear programming relaxation can be quite weak". Proposed fix: a successive refinement algorithm that partitions the support and tightens mean-value lower bounds inside branch-and-cut; literature note: "The existing literature on SP-EPs has largely avoided the issue of high nonlinearity by using decoupling, recursive nonlinearization, or approximations". — [arXiv 2409.08403](https://www.arxiv.org/pdf/2409.08403)
- Basciftci, Ahmed, Shen (EJOR 292(2), 548–561, 2021): demand d_j(y) with moments μ_j(y) = min{μ̄_j(1 + Σ_{j'} λ^μ_{jj'} y_{j'}), μ^UB_j}, σ_j²(y) = max{σ̄_j²(1 − Σ_{j'} λ^σ_{jj'} y_{j'}), (σ^LB_j)²} (eq. 2); model min_y f'y + max_{π∈U(y)} E_π[h(y, d(y))] with recourse h = min Σ c_ij x_ij + Σ(p_j s_j − r_j d_j) s.t. Σ_i x_ij + s_j = d_j, x_ij ≤ C_i y_i (eq. 3–4); ambiguity set U(y) = {π : Σ_k π_jk = 1, |Σ_k π_jk d_k − μ_j(y)| ≤ ε^μ_j, (σ_j²(y)+μ_j(y)²)ε̲ ≤ Σ_k π_jk d_k² ≤ (σ_j²(y)+μ_j(y)²)ε̄} (eq. 1). Proposition 1: the recourse LP decomposes by customer and by LP duality has closed form h_j = max_{i*=0..|I|}{c_{i*j} d_j(y) + Σ_{i: c_ij < c_{i*j}} C_i y_i (c_ij − c_{i*j})} − r_j d_j(y). Theorem 1: the whole problem equals min f'y + Σ_j [α_j + δ_j¹(μ_j(y)+ε) − δ_j²(μ_j(y)−ε) + γ_j¹(σ_j²(y)+μ_j(y)²)ε̄ − γ_j²(...)ε̲] s.t. α_j + (δ_j¹−δ_j²)d_k + (γ_j¹−γ_j²)d_k² ≥ θ_jk(y) ∀j,k. The objective is then bilinear/trilinear (continuous dual × binary, continuous × binary × binary) and is linearized exactly with McCormick sets M' (eq. 13) and M'' (eq. 14, Prop. 2: M'' = conv{w = ηz_1 z_2, η ∈ [η̲, η̄], z ∈ {0,1}²}), giving the MILP of Theorem 2; valid inequalities derived from Prop. 1 (Prop. 3). — [arXiv 1912.05577](https://arxiv.org/pdf/1912.05577); [IDEAS EJOR record](https://ideas.repec.org/a/eee/ejores/v292y2021i2p548-561.html)
- Related decision-dependent DRO: Luo & Mehrotra (arXiv 1806.09215) — decision-dependent ambiguity sets via moments, Wasserstein, φ-divergence, Kolmogorov–Smirnov; finite support duality yields reformulations solvable by global optimization, some "non-convex semi-infinite programs". — [arXiv 1806.09215](https://arxiv.org/pdf/1806.09215). Noyan, Rudolf, Lejeune (INFORMS J. Computing 34(2), 729–751, 2022): balls (earth-mover distances) centered on a decision-dependent distribution; applications to scheduling and humanitarian logistics. — [IDEAS](https://ideas.repec.org/a/inm/orijoc/v34y2022i2p729-751.html). Service-center location with "decision dependent demand induced from a maximum attraction principle" (DRO). — [arXiv 2011.12514](https://arxiv.org/pdf/2011.12514)
- Recent: "The L-Shaped Method for Stochastic Programs with Decision-Dependent Uncertainty" (arXiv 2506.12753, 2025) — surfaced by search; content not read. — [arXiv 2506.12753](https://arxiv.org/pdf/2506.12753)

### Inferences
- The Basciftci–Ahmed–Shen route is the one most directly applicable to Σ_s p_s(y) Q_s(y): (1) make the y-dependence of the demand distribution affine (or piecewise-linear with extra binaries) in y; (2) collapse the second-stage LP by strong duality so Q_s(y) = max over dual extreme points of (affine in y); (3) the resulting objective has products (dual variable or dual-extreme-point constant) × y_i × y_j, which McCormick linearizes exactly because y is binary. The price is a weak LP relaxation (Medal–Affar's observation) and the loss of the Benders/L-shaped structure, since the "scenario weights" are no longer constants. This does not need concavity of p_s in y and does not need Q_s constant — it needs p_s affine (or low-degree multilinear) in y.
- Logit-type p_s(y) is not affine; the Hellemo "rational approximation" and the Charnes–Cooper variable of KQ2 are the two documented ways to bring a ratio into this framework, both at the cost of a continuous auxiliary variable whose product with y and with the dual variables is no longer McCormick-exact.
- Convex-combination form (Hellemo): p_s(y) = Σ_m λ_m(y) p_s^m with λ_m(y) affine in y gives Σ_s p_s(y) Q_s(y) = Σ_m λ_m(y) [Σ_s p_s^m Q_s(y)] = Σ_m λ_m(y) E_m[Q(y)]: a sum of (affine in y) × (expected recourse under a fixed distribution). When λ_m(y) = y_i (one "mixture component per facility") this is binary × convex value function, which is exactly linearizable by the "y_i Q^m(y) = Q^m(y) − (1 − y_i)·Q^m(y)" indicator trick or by Benders cuts on θ_m with activation by y_i — i.e., a "menu of distributions indexed by facilities". This is my reading of the mixture form; Hellemo et al.'s own handling (BARON) was not read.

### Gaps
- Hellemo et al.'s full text (taxonomy Type 1/Type 2 and the exact affine-distortion equations) could not be retrieved (Springer and MIT bitstream downloads failed); only the abstract is cited.
- The 2025 L-shaped-for-DDU paper and the maximum-attraction DRO paper were not read; whether they offer cuts valid for the product form is unknown.

## Key Question 9 (cross-cutting): Which formulations change the variables, which structural property each uses, and which survive when the payoff is a second-stage LP value Q_s(y)

### Takeaway
Across all seven literatures the bilinearity "distribution × payoff" is removed by one of four moves — (A) fix the distribution and solve a convex program per candidate (Grossman–Hart Step 1, full enumeration); (B) exploit that the payoff is a constant so the objective inherits concavity/submodularity or a conic form from the share function (MCFL cuts, Şen–Atamtürk conic, revenue ordering); (C) re-parameterize by the induced demand/sales/intensity when the decision-to-demand map is a bijection with concave revenue (Gallego–van Ryzin, SBLP); (D) keep y as the variable, make the distribution affine/multilinear in y, dualize the inner LP and McCormick-linearize dual × binary products (Basciftci–Ahmed–Shen, Medal–Affar). Only (D) is documented to survive a y-dependent recourse LP, and it gives an exact but weak-relaxation MILP, not a convex program.

### Cited Findings
- (A) Grossman–Hart: convex program per action; enumeration over actions. — [Econometric Society](https://www.econometricsociety.org/publications/econometrica/1983/01/01/analysis-principal-agent-problem); [Georgiadis notes](https://www.kellogg.northwestern.edu/faculty/georgiadis/Teaching/Ec515_Module5.pdf)
- (B) concavity/submodularity of the logit share with constant weights q_n; OA and submodular cuts. — [arXiv 2403.04264v2](https://arxiv.org/html/2403.04264v2); conic rotated cones y_i w_i ≥ 1, z_ij w_i ≥ x_j² requiring nonnegative constant coefficients. — [arXiv 1705.09040](https://arxiv.org/pdf/1705.09040)
- (C) intensity as decision variable with concave r(λ); convex deterministic program. — [Gallego & van Ryzin 1994](https://business.columbia.edu/sites/default/files-efs/pubfiles/3943/vanryzin_optimal_dynamic_pricing.pdf); sales variables with balance/scale constraints. — [SBLP](https://business.columbia.edu/sites/default/files-efs/imce-uploads/CPRM/2011-4-GAMplusSBLPv8.pdf)
- (D) affine moments in y, strong duality on the recourse LP, McCormick on products with binaries (exact, Prop. 2). — [arXiv 1912.05577](https://arxiv.org/pdf/1912.05577); multilinear p_s(x) with McCormick "exact for binary solutions" but "linear programming relaxation can be quite weak". — [arXiv 2409.08403](https://www.arxiv.org/pdf/2409.08403)
- Convexity of stochastic bilevel objectives holds only when the upper level depends solely on the lower-level optimal value (fixed probabilities). — [Beck et al. survey](https://opus4.kobv.de/opus4-trr154/files/491/bilevel-under-uncertainty-survey-preprint.pdf)
- MLRP + CDFC make the agent's expected utility concave in the action for a fixed, monotone payoff schedule. — [Georgiadis notes](https://www.kellogg.northwestern.edu/faculty/georgiadis/Teaching/Ec515_Module5.pdf); [Rogerson 1985](https://www.econometricsociety.org/publications/econometrica/1985/11/01/first-order-approach-principal-agent-problems)

### Inferences
- A candidate "Charnes–Cooper on the whole two-stage program" (my derivation, not sourced): if all p_s(y) share one affine positive denominator D(y) = U + Σ_i V_i y_i and numerators N_s(y) = V_s y_s (MNL with scenario = captured facility), set w = 1/D(y), u_i = y_i w (McCormick-exact), and scale the recourse: w·Q_s(y) = min{c'x̃ : A x̃ = w b_s, x̃ ≤ C u} =: Q̃_s(w,u), an LP value jointly convex in (w,u). Then Σ_s p_s(y)Q_s(y) = Σ_s V_s y_s Q̃_s(w,u), and because the LP value function is positively homogeneous in its RHS, y_s Q̃_s(w,u) = Q̃_s(y_s w, y_s u) = Q̃_s(u_s, (y_s y_i w)_i); the trilinear terms y_s y_i w are McCormick-exact for binaries (Basciftci Prop. 2 type). Result: an exact MILP whose objective is a sum of LP values of linear functions of auxiliary variables — route (D) applied to a logit distribution. Limitations: needs a common denominator (single customer segment, or zone-separable recourse so each zone can be scaled by its own w_n), introduces |S|·n trilinear auxiliaries, and the relaxation is expected to be weak as in Medal–Affar.
- A CDFC/MLRP-style sufficient condition for convexity of the continuous relaxation (my derivation): with scenarios ordered so Q_1 ≥ ... ≥ Q_S and constant Q_s, Σ_s p_s(y) Q_s = Q_S + Σ_{s<S} F_s(y)(Q_s − Q_{s+1}) is convex in y whenever each cumulative F_s(y) is convex in y. This mirrors Rogerson's CDFC exactly, and fails to extend when Q_s depends on y.
- Submodularity route from (B) extends to the target problem only if the set function y ↦ Σ_s p_s(y) Q_s(y) is submodular; a sufficient but unverified condition would be that each Q_s(·) is supermodular-decreasing and p_s(·) is a nonnegative monotone submodular capture share with Q_s constant; no source establishes this.

### Gaps
- No paper found that performs the "Charnes–Cooper on the recourse" scaling above; it is proposed here as an inference for the OR to validate.
- No source gives conditions under which the product of a decision-dependent probability and an LP value function is convex, submodular, or admits valid OA cuts; this is the central open question and it is absent from all literatures surveyed (consistent with the Beck et al. survey calling decision-dependent uncertainty in bilevel "completely open").
