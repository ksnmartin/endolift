# Verification of the four derived reformulations of F(y) = sum_s p_s(y) Q_s(y)

Scope: independent mathematical verification plus numerical checks of Candidates 1-4 as stated in the earlier notes (`variational_physics.md` KQ1, `global_opt_submodularity.md` Q1/Q2/Q8, `economics_bilevel.md` Q7, `mdp_rl_ideas.md` KQ2). Everything marked **(derived)** is my own derivation in this session; everything with a URL is a cited fact. The numerical checks were throwaway scripts on the toy instance of Q0 (LP/MILP through HiGHS, exponential cones through Clarabel) and are not kept; the numbers quoted below are their converged outputs.

Notation used throughout: y in {0,1}^n; Q_s(y) = min{c^T x : A x = d_s, B x <= U y, x >= 0} = max_k (alpha_k^T d_s - g_k^T y) with g_k = U^T beta_k over dual vertices k ("cuts"); m_x = dim x, m_A = rows of A, m_B = rows of B; K = cuts per scenario; "MC-P" = naive McCormick on omega_s = p_s(y) theta_s with p_s(y) and theta_s both continuous; "MC-B" = Basciftci-type McCormick on z_sj = y_j theta_s (binary x continuous).

## Q0. Toy instance and baseline used for all numerical checks

### Takeaway
One capacitated facility-location recourse (n = 3 sites, m = 4 customers, unmet-demand penalty, so recourse is relatively complete and every dual vertex has beta_i <= penalty) was combined with three probability models (affine, Gibbs, logit); three instances each (S = 4 and S = 8 with demand seed 1, S = 6 with demand seed 2). All relaxations were run with cut loops to convergence so that each reported LP bound is the bound of that formulation with the *complete* Benders cut family, not an artefact of cut selection.

### Cited Findings
- Baseline McCormick set for binary x bounded-continuous products and its exactness ("Because variable z is binary valued, we have an exact reformulation in (13)"), and the trilinear hull of Proposition 2 — [Basciftci, Ahmed & Shen, arXiv 1912.05577](https://arxiv.org/abs/1912.05577) (as quoted in `or_baseline.md` KQ2 and `change_of_measure.md` Q8).
- Four McCormick inequalities are the convex envelope of a single bilinear term over its box (used for MC-P) — McCormick 1976 as summarised in `global_opt_submodularity.md` Q1 and [arXiv 2208.00345](https://arxiv.org/abs/2208.00345).

### Inferences
- **(derived) Instance.** cap = (8, 7, 9), fixed cost f = (10, 9, 12), penalty 10, transport cost C (site x customer) = [[3.5, 2.1, 1.2, 1.1], [4.3, 4.7, 3.4, 3.9], [3.2, 4.7, 4.3, 1.0]]. Demands for S = 4, seed 1: d = [[1.52, 2.18, 0.97, 2.17], [2.11, 2.40, 3.45, 2.36], [3.88, 1.95, 4.64, 3.84], [3.98, 6.18, 3.86, 4.58]] (scenario totals rise from 6.8 to 18.6, so probability shifts matter). Recourse LP: sum_i x_ik + u_k = d_sk, sum_k x_ik <= cap_i y_i. Q_s(y) at the 8 binary points ranges from 12.8 to 186.0; 8 distinct dual vertices per scenario are active at binary points.
- **(derived) Probability models.** Affine: p_s(y) = 1/S + sum_j a_sj y_j with a_sj = shift_s * c_j * 4/S, shift = linspace(-1, 1, S) centred (so sum_s a_sj = 0), c = (0.0713, 0.0849, 0.0788); p_s >= 0.015 at all binary points. Gibbs: q_s = 1/S, beta = 1, E_s(y) = a_s^T y with a_sj = -shift_s * (0.3386, 0.4498, 0.4804)_j (opening lowers the energy of high-demand scenarios). Logit: N_s(y) = 1 + sum_j nu_sj y_j, nu_sj = linspace(0.1, 1.5, S)_s * (1.244, 1.246, 1.012)_j, D(y) = sum_s N_s(y) = 4 + (3.98, 3.99, 3.24) y.
- **(derived) Exact optima by enumeration (f^T y + F(y)).** Affine: 54.1972 (S4), 56.1032 (S8), 61.0654 (S6/seed 2); Gibbs: 56.3003, 58.2178, 64.3262; logit: 53.8404, 55.7492, 60.5684; y* = (1, 0, 1) in all nine cases.
- **(derived) An important fact about the baseline.** MC-P (McCormick on omega_s = p_s(y) theta_s with p_s(y) affine-continuous) is **not** an exact reformulation at binary y: with y fixed to a binary point it under-estimates F(y) by up to 12.3 (affine), 13.9 (Gibbs), 7.0 (logit) because p_s(y) sits strictly inside its bounds [p_min, p_max] and theta_s is continuous. Only MC-B (products y_j theta_s) is exact (error 1.4e-14). MC-P is therefore a *relaxation only*; it is reported because the task defines it as the baseline, but the exact-MILP baseline is MC-B.
- Bounds used for the baselines were the tightest valid ones, theta_s in [min_y Q_s(y), max_y Q_s(y)] over binary y, and also 2x and 10x the upper bound; probability bounds [p_min, p_max] likewise from enumeration. This favours McCormick as much as possible.

### Gaps
- Only n = 3; LP relaxations of 3-site instances are close to integral, so absolute gaps are small for all good formulations; rankings, not magnitudes, are the transferable information.

## Q1. Candidate 1 (Gibbs / KL exact mixed-integer exponential-cone program)

### Takeaway
Correct and exact (proved; verified to solver tolerance), with a jointly convex continuous relaxation that is a valid lower bound; but (i) the exactness rests on a value-function ("optimal-value reformulation") constraint whose feasible set is a single point at every binary y, so Slater fails there and interior-point solvers return `optimal_inaccurate` with systematically optimistic values; and (ii) the relaxation is *far weaker* than naive McCormick (33-42 % gap with the strengthening versus 3.6-7 % for the naive baseline), because McCormick on w_sj = r_s y_j is almost vacuous when r_s <= 1/2.

### Cited Findings
- Gibbs variational principle / Donsker-Varadhan: log sum_s q_s e^{f_s} = max_r {E_r f - KL(r||q)}, attained at the Gibbs tilt — [arXiv 2609.11339](https://arxiv.org/pdf/2609.11339) (via `variational_physics.md` KQ1); the KL-gap identity itself is stated as "(EXACT, derived here)" in `variational_physics.md` KQ1 and is re-proved below.
- Perspective reformulation and its convex hull property for indicator-type on/off sets — Günlük & Linderoth, Math. Program. 124 (2010) 183-205, [DOI 10.1007/s10107-010-0360-z](https://link.springer.com/article/10.1007/s10107-010-0360-z) (cited, not re-fetched; summarised in `global_opt_submodularity.md` Q1).
- Optimal-value (value-function) reformulations of bilevel programs violate MFCQ at every feasible point — Ye & Zhu, Optimization 33 (1995) 9-27, [DOI 10.1080/02331939508844060](https://doi.org/10.1080/02331939508844060) (cited from memory, not re-fetched this session).
- Pinsker's inequality ||r - p||_1 <= sqrt(2 KL(r||p)) — standard (Cover & Thomas, Elements of Information Theory, Lemma 11.6.1).

### Inferences
- **(derived) Statement.** p_s(y) = q_s exp(-beta E_s(y))/Z(y), E_s(y) = a_s^T y + b_s. Program: min f^T y + sum_s c^T x_s over y in {0,1}^n, r in Delta_S, w in R^{S x n}, x_s >= 0, subject to A x_s = r_s d_s, B x_s <= U w_s, McCormick(w_sj = r_s y_j), optional sum_s w_sj = y_j, and G(r, w, y) := sum_s r_s log(r_s/q_s) + beta sum_s (a_s^T w_s + b_s r_s) + log sum_s q_s exp(-beta(a_s^T y + b_s)) <= 0.
- **(derived) Proof of the identity.** KL(r||p(y)) = sum_s r_s log r_s - sum_s r_s [log q_s - beta E_s(y) - log Z(y)] = KL(r||q) + beta sum_s r_s E_s(y) + log Z(y), using sum_s r_s = 1. Nonnegativity and the equality case r = p(y) are Gibbs' inequality. Hence {r : KL(r||p(y)) <= 0} = {p(y)} and min_r {sum_s r_s Q_s(y) : KL(r||p(y)) <= 0} = F(y) trivially (the feasible set is a singleton, so the "min over r" does nothing at binary y).
- **(derived) Proof of exactness of the lifted program at binary y.** McCormick on (w_sj, r_s, y_j) with y_j in {0,1} forces w_sj = r_s y_j; then G = KL(r||p(y)) and the constraint forces r = p(y). For the recourse, the feasible set {x : A x = t d_s, B x <= t U y, x >= 0} equals t times the feasible set at t = 1 for t > 0, so min c^T x_s = r_s Q_s(y) when r_s > 0; when r_s = 0 the constraints are A x_s = 0, B x_s <= 0, x_s >= 0, and dual feasibility (c >= A^T alpha - B^T beta, beta >= 0, which holds whenever Q_s(y) is finite) gives c^T x_s >= alpha^T A x_s - beta^T B x_s >= 0, so the minimum is 0 = r_s Q_s(y). Exact. Numerically: enumerating y and solving the convex program gives 56.3001 vs F* = 56.3003 (S4), 58.2171 vs 58.2178 (S8), 64.3244 vs 64.3262 (S6/seed 2): differences of 1e-4 to 2e-3 are solver effects (next bullet), not modelling errors.
- **(derived) Convexity in (r, w, y).** rel_entr(r_s, q_s) is jointly convex; the w- and r-terms are linear; log-sum-exp of an affine function of y is convex. So G <= 0 is a convex exponential-cone constraint and the continuous relaxation (y in [0,1]^n) is a convex program. The bilinear term r_s a_s^T y is the *only* non-convexity and the McCormick lift removes it. Confirmed: yes, convex once w replaces r_s y_j.
- **(derived) Slater fails exactly at binary y, and it is the generic bilevel pathology.** p(y) = argmin_r {KL(r||q) + beta sum_s r_s E_s(y)} with optimal value -log Z(y), so "G <= 0" is the optimal-value reformulation of a convex lower-level problem; such constraints never admit a strictly feasible point (min G = 0), which is the Ye-Zhu MFCQ failure. At fractional y the relaxation generically *does* have Slater points (take w_sj = max(0, r_s + y_j - 1) < r_s y_j for a_sj > 0, or w_sj = min(r_s, y_j) > r_s y_j for a_sj < 0, which strictly decreases the linear term below KL(r||p(y)) at r = p(y)). So the failure bites precisely in the branch-and-bound nodes where all y are fixed, and in any OA/Benders scheme that fixes y.
- **(derived) Measured effect of the Slater failure.** Fixing y at each of the 8 binary points and solving with CLARABEL (eps = 0): statuses include `optimal_inaccurate` on every instance (all 8 points on S8 and S6), returned values are *below* F(y) by between 1.2e-4 and 0.134 (<= 0.2 % of F) with max |r - p(y)| up to 1.7e-3. The error is one-signed (optimistic) because r is minimised over: any numerical slack in G <= 0 is spent moving mass to cheap scenarios. With the Slater-restoring slack G <= eps: eps = 1e-6 gives errors to -0.20, eps = 1e-3 gives errors to -2.54 (4 % of F). SCS at y* returned -1.5 (`optimal_inaccurate`) on the seed-2 instance. Pinsker bounds the eps-error by (max_s Q_s - min_s Q_s) sqrt(eps/2) (via |sum_s (r_s - p_s) Q_s| <= (max Q - min Q) ||r - p||_1 / 2), e.g. <= 2.6 at y = 0 for eps = 1e-3, consistent with the observed -1.96. Remedy: at nodes with all y fixed, substitute r = p(y) and solve the plain LP; use the KL program only at fractional nodes, where Slater holds.
- **(derived) Valid lower bound.** The relaxation's feasible set contains every binary-feasible point with its exact objective, so its value is a valid lower bound on min F; this is inclusion, nothing more. At fractional y the relaxation's value is *not* F(y) and r != p(y) (see next bullet), so it is not a "convex extension" of F; it is a lifted relaxation like any other.
- **(derived) Relaxation is much weaker than naive McCormick (numbers).** Gap of the continuous relaxation vs the exact optimum: without the strengthening sum_s w_sj = y_j: 54.4 % (S4), 58.8 % (S8), 62.0 % (S6/seed 2); with it: 33.2 %, 34.4 %, 41.9 %. Naive McCormick baseline for the same Gibbs model (p_s represented via the exact binary expansion exp(-beta a_s^T y) = prod_j (1 + (e^{-beta a_sj} - 1) y_j) with Charnes-Cooper variable w = 1/Z and McCormick on p_s theta_s): 4.0 %, 3.6 %, 7.1 % (insensitive to the theta bound U between Qmax and 10 Qmax). Candidate 1 with the recourse in naive McCormick form r_s theta_s instead of the perspective LP: 59.0 %, 60.7 %, 64.1 %.
- **(derived) Why the relaxation is weak.** At the strengthened relaxation optimum of S4, y = (0.914, 0.059, 0.441), r = (0.331, 0.253, 0.216, 0.201) while p(y) = (0.133, 0.192, 0.277, 0.398): the relaxation puts the most mass on the cheapest scenario. It can because G(r, w, y) = 0.001 at the chosen w while KL(r||p(y)) = 0.18 at w = r (x) y; the McCormick lower bound max(0, r_s + y_j - 1) is 0 whenever y_j <= 1 - r_s, which is almost always the case for S >= 2 (r_s <= 1/2), so the term beta a_s^T w_s can be driven to its minimum and the KL constraint carries almost no information about y. This is structural: the lift w = r (x) y has one continuous factor in [0, 1/2] and the McCormick box is loose precisely there. The "perspective" half of the formulation (scaled recourse, no bound on Q) is fine; the probability half is what fails.
- **(derived) Benders combination works and is value-preserving.** The scaled recourse has the same dual polyhedron as Q_s, so cuts generated anywhere transfer as eta_s >= (alpha_k^T d_s) r_s - g_k^T w_s; the cut version converges to the same relaxation value (37.5993 = LP value on S4; 38.2015 and 37.3820 on the other two) in 6 iterations. Master = exponential-cone program with linear cuts in (eta, r, w); a MICP (OA or nonlinear B&B) master is required, and the Slater issue above appears at integer nodes.
- **(derived) Size.** Variables: n + S + Sn + S m_x (perspective LP) or n + S + Sn + S (with cuts). Constraints: 4Sn McCormick + n strengthening + 1 exponential-cone constraint (S relative-entropy terms + one S-term log-sum-exp, i.e. 2S exponential cones in conic form) + S(m_A + m_B) recourse rows or S K cuts.

### Gaps
- No tightening of the w = r (x) y lift beyond sum_s w_sj = y_j was found that keeps the program convex; an exact convex description of {(r, w, y): w = r (x) y, y binary, r = p(y)} is the whole problem.
- The Ye-Zhu reference is cited from memory; the MFCQ-failure statement is classical but should be checked against the paper before quoting.

## Q2. Candidate 2 (Benders cuts multiplied by p_s(y), lifted monomials)

### Takeaway
Validity, global validity of cuts, exactness at binary y and finite Benders convergence are all correct (proved; verified, including Benders from an empty master converging in 4 iterations on every instance). The tightness claim is false as stated: multiplying each cut by the *whole* p_s(y), which has mixed-sign coefficients, is sometimes weaker than Basciftci-McCormick (4.99 % vs 1.98 % on S4) and sometimes stronger (1.83 % vs 1.96 % on S6/seed 2). Splitting p_s(y) into its nonnegative literal factors (posiform: constant, y_j, 1 - y_j) and multiplying each cut by each factor with its own epigraph variable yields a bound-free formulation that provably dominates MC-B for every valid U (1.96/1.54/0.97 % vs 1.98/1.77/1.96 %); the explicit level-1 RLT LP (Adams-Sherali two-copy form) dominates that again and was integral (0.00 % gap) on all three n = 3 instances.

### Cited Findings
- Standard linearization describes the multilinear polytope iff the hypergraph is Berge-acyclic; polynomial-size extended formulations for acyclic hypergraphs — [Del Pia & Khajavirad, arXiv 2501.04805](https://arxiv.org/html/2501.04805v1) (via `global_opt_submodularity.md` Q2).
- Boolean quadric polytope and triangle inequalities — Padberg, Math. Program. 45 (1989) 139-172, [DOI 10.1007/BF01589101](https://doi.org/10.1007/BF01589101) (cited, not re-fetched).
- Mixed 0-1 RLT (multiplying constraints by y_j and 1 - y_j) and its relaxation dominance — Adams & Sherali, Oper. Res. 38 (1990) 217-226, [IDEAS record](https://ideas.repec.org/a/inm/oropre/v38y1990i2p217-226.html) (via `change_of_measure.md` Q8).
- Candidate statement: "RLT-multiplied Benders cuts ... exact at binary y, no bound on Q_s" — `global_opt_submodularity.md` Q1 and Q9 (B).

### Inferences
- **(derived) Statement (affine p).** p_s(y) = b_s + a_s^T y; Y_jl = y_j y_l (Y_jj = y_j) with the standard linearization; cuts eta_s >= (alpha_k^T d_s) p_s(y) - g_k^T ytilde_s(y, Y), ytilde_s,l = b_s y_l + sum_j a_sj Y_jl; objective f^T y + sum_s eta_s.
- **(derived) Proof of validity and global validity.** For binary y, p_s(y) >= 0 and Q_s(y) >= alpha_k^T d_s - g_k^T y, so p_s(y) Q_s(y) >= p_s(y)(alpha_k^T d_s - g_k^T y), with equality for the vertex k optimal at y; since p_s(y) is a nonnegative scalar, max_k p_s(y) cut_k(y) = p_s(y) max_k cut_k(y) = p_s(y) Q_s(y). In the lifted space the right-hand side is linear in (y, Y), so the inequality holds at every point of X = {(y, Y, eta): y binary, Y = y y^T, eta_s >= p_s(y) Q_s(y)}, hence on conv X and on every relaxation of conv X; cuts generated at any (fractional or binary) point stay valid everywhere. At a binary master point the standard linearization forces Y = y y^T, the optimal vertex's cut closes the gap, and there are finitely many vertices: finite convergence. Numerically: value at fixed binary y equals F(y) to 2.8e-14 on all 8 points; MILP optimum = enumeration optimum on all instances; Benders from an empty master converged in 4 iterations with 3-4 cuts per scenario.
- **(derived) Separation at fractional (y, Y).** The most violated lifted cut for scenario s is the dual vertex optimal for the LP with right-hand side p_s(y) d_s and capacity U ytilde_s(y, Y); when ytilde has negative entries the dual is unbounded, and a dual box 0 <= beta <= penalty (valid here because every vertex satisfies it) yields a valid truncated cut. This is one LP per scenario, same cost as ordinary Benders.
- **(derived) Counterexample to "tighter than McCormick".** S4/seed 1: Candidate 2 relaxation 51.491 (gap 4.99 %, same with Padberg triangle inequalities), MC-B with U = Qmax 53.124 (1.98 %), MC-B with U = 2 Qmax 52.847 (2.49 %), MC-B with U = 10 Qmax 52.711 (2.74 %); MC-P 52.686 (2.79 %, independent of U). S8/seed 1: C2 3.23 % vs MC-B 1.77/2.13/2.64 %. S6/seed 2: C2 1.83 % vs MC-B 1.96/3.70/4.68 %. So neither formulation dominates the other. Mechanism: at the C2 relaxation point (y = (0.788, 0.458, 0.788), Y_jl = min(y_j, y_l)) the high-demand scenarios (a_sj > 0) have negative coefficients on Y in the cut and push Y to its McCormick upper bound, while a single max_k is applied to the whole mixed-sign combination; MC-B instead keeps both the lower *and* upper McCormick envelopes of each product y_j theta_s, which is information the "multiply the whole cut" scheme discards.
- **(derived) Repair: per-factor (posiform) multiplication, with a dominance proof.** Write p_s(y) = b'_s + sum_{a_sj > 0} a_sj y_j + sum_{a_sj < 0} |a_sj| (1 - y_j), b'_s = b_s + sum_{a_sj < 0} a_sj = min over binary y of p_s(y) >= 0. Each factor lambda in {1, y_j, 1 - y_j} is nonnegative on {0,1}^n, so p_s Q_s = b'_s Q_s + sum a_sj (y_j Q_s) + sum |a_sj| ((1 - y_j) Q_s) with separate epigraphs eta^0_s >= cut_k(y), eta^+_sj >= alpha_k^T d_s y_j - g_k^T Y_j, eta^-_sj >= alpha_k^T d_s (1 - y_j) - g_k^T (y - Y_j), for all k. (i) Exact at binary y (each term is a nonnegative scalar times Q_s). (ii) For fixed (s, j), the set {(y_j, y, v): y_j in {0,1}, y in [0,1]^n, v >= y_j Q_s(y)} is the union of P0 = {y_j = 0, Y_j = 0, v >= 0} and P1 = {y_j = 1, Y_j = y, v >= Q_s(y)}; Balas' disjunctive hull with multiplier lambda = y_j is exactly {0 <= Y_j <= y_j 1, 0 <= y - Y_j <= (1 - y_j) 1, v >= y_j Q_s(Y_j / y_j) = max_k (alpha_k^T d_s y_j - g_k^T Y_j)}: the McCormick inequalities for Y_j = y_j y plus the per-factor cuts. So the per-factor cuts give the convex hull of each single product (the Günlük-Linderoth perspective hull with a piecewise-linear function). (iii) MC-B's inequalities z_sj >= L y_j, z_sj >= theta_s - U(1 - y_j), theta_s - z_sj >= L (1 - y_j), theta_s - z_sj >= theta_s - U y_j are valid for the same two polyhedra (with theta_s >= Q_s(y) and Q_s <= U), hence implied by their hull. Therefore per-factor C2 <= MC-B for every valid U, with no bound at all. (iv) Per-factor dominates whole-p C2 because eta_s >= max_k sum_terms(k) <= sum_terms max_k. Numbers: 53.132 (1.96 %), 55.242 (1.54 %), 60.474 (0.97 %) vs best MC-B 1.98 %, 1.77 %, 1.96 %. Cost: S(1 + 2n) epigraph variables (only S(1 + nnz(a_s)) are needed) and S K (1 + 2n) cuts.
- **(derived) Explicit level-1 RLT LP dominates the per-factor cuts and was integral here.** Keep x_s explicitly and the two product copies z_sj = y_j x_s: A z_sj = y_j d_s, B z_sj <= U Y_j, A(x_s - z_sj) = (1 - y_j) d_s, B(x_s - z_sj) <= U(y - Y_j), z_sj >= 0, x_s - z_sj >= 0, objective sum_s [b_s c^T x_s + sum_j a_sj c^T z_sj] = sum_s [b'_s c^T x_s + sum_+ a_sj c^T z_sj + sum_- |a_sj| c^T (x_s - z_sj)]. Weak duality on each block shows any feasible point of this LP yields a feasible point of the per-factor cut formulation with the same objective (so RLT-LP >= per-factor cuts); the converse fails because the cut version does not force one common x_s. Exact at binary y (1.4e-14) and the relaxation gap was 0.00 % on all three affine instances (y relaxed to (1, 0, 1) directly). Cost: S n m_x extra variables and S n (2 m_A + 2 m_B + 2 m_x) rows. With n = 3 this integrality should not be extrapolated; it does show that the bound-free RLT family is where the strength is, and that cuts projected scenario-wise lose part of it (the same loss appears in Candidate 3: 42.3 vs 50.2).
- **(derived) Size of the lifted space.** Affine p: n(n - 1)/2 shared Y variables, 3 n(n - 1)/2 standard-linearization rows (+ 4 triangle rows per triple if used; they changed nothing here), S epigraphs, S K cuts, each cut dense in n + n(n - 1)/2 lifted variables. Multilinear p of degree d: monomials of degree <= d + 1, sum_{t <= d+1} C(n, t) = O(n^{d+1}) variables, O(|M|) standard-linearization rows per monomial M; exactness of the monomial relaxation only when the monomial hypergraph is Berge-acyclic (Del Pia-Khajavirad), otherwise the multilinear polytope needs more. The per-factor repair for multilinear p requires a representation of p_s as a nonnegative combination of literal monomials; the degree-preserving one need not exist, and the always-available one (Lagrange expansion sum_T p_s(1_T) prod_{j in T} y_j prod_{j notin T} (1 - y_j)) has 2^n terms and is scenario-pattern enumeration (then the LP is exact and is the one-hot formulation). The two ends of this trade-off are: whole-p multiplication (cheap, weak) and full enumeration (exact, 2^n).

### Gaps
- No source states the convex hull of {(y, w): w >= y_k Q(y)} for piecewise-linear convex Q; the Balas-hull derivation above fills that gap but is mine.
- Whether the explicit RLT-1 LP remains integral for larger n is untested; expect no (the standard linearization of Y is not the Boolean quadric polytope for n >= 3 in general).

## Q3. Candidate 3 (Charnes-Cooper on the whole two-stage program)

### Takeaway
All steps are correct: positive homogeneity of the LP value function, the identity sum_s p_s Q_s = sum_s N_s(y) Qtilde_s(w, u), the linear normalization D_0 w + sum_j D_j u_j = 1, and McCormick-exactness of the products N_s(y) x~_s (given bounds on x~; a bound-free RLT variant is also exact). Verified: 2.8e-14 error at binary points and MILP optimum = enumeration on three instances. The relaxation is weak: 6.8-7.5 % with the RLT variant and 54-55 % with the McCormick-on-x~ variant as stated, versus 2.8-4.9 % for naive McCormick on the same logit model, because (w, u) decouple from y in the relaxation and the scaled recourse receives capacity ratio u/w larger than y.

### Cited Findings
- Charnes-Cooper transformation for linear-fractional programs — Charnes & Cooper, Naval Res. Logist. Q. 9 (1962) 181-186, [DOI 10.1002/nav.3800090303](https://doi.org/10.1002/nav.3800090303) (cited, not re-fetched); conic assortment use — Şen, Atamtürk & Kaminsky, Oper. Res. 66 (2018), [DOI 10.1287/opre.2017.1703](https://doi.org/10.1287/opre.2017.1703) (cited, not re-fetched; summarised in `economics_bilevel.md` KQ2).
- The candidate as stated — `economics_bilevel.md` Q7 inference ("Charnes-Cooper on the whole two-stage program", flagged there as unsourced and "expected to be weak as in Medal-Affar").

### Inferences
- **(derived) Statement.** p_s(y) = N_s(y)/D(y), N_s(y) = nu_s0 + sum_j nu_sj y_j >= 0, D(y) = sum_s N_s(y) = D_0 + sum_j D_j y_j > 0. Variables w = 1/D(y) in [1/D_max, 1/D_min], u_j = y_j w (McCormick, exact: binary x bounded continuous), Y_jl = y_j y_l, v_jl = Y_jl w (McCormick on a 0/1 variable times w; v_jj = u_j), x~_s, z_sj = y_j x~_s. Constraints: A x~_s = w d_s, B x~_s <= U u, D_0 w + sum_j D_j u_j = 1, and either (McCormick form) 0 <= z_sj <= xbar_s y_j, x~_s - xbar_s (1 - y_j) <= z_sj <= x~_s, or (RLT form) A z_sj = u_j d_s, B z_sj <= U v_j, A(x~_s - z_sj) = (w - u_j) d_s, B(x~_s - z_sj) <= U(u - v_j), z_sj >= 0, x~_s - z_sj >= 0. Objective f^T y + sum_s [nu_s0 c^T x~_s + sum_j nu_sj c^T z_sj].
- **(derived) Homogeneity.** For t > 0, {x : A x = t d, B x <= t U y, x >= 0} = t {x : A x = d, B x <= U y, x >= 0}, so Qtilde_s(t, t y) = t Q_s(y); with t = w = 1/D(y) and u = w y this is w Q_s(y). Numerically w Q_1(y*) = 1.138677 = Qtilde_1(w, w y*). The normalization is linear because D(y) w = D_0 w + sum_j D_j (y_j w) = D_0 w + sum_j D_j u_j.
- **(derived) Exactness.** sum_s N_s(y) min_x~ c^T x~ = min_{x~_1..x~_S} sum_s N_s(y) c^T x~_s because N_s(y) >= 0 and the blocks are separate. N_s(y) c^T x~_s = nu_s0 c^T x~_s + sum_j nu_sj c^T (y_j x~_s): binary times bounded continuous, McCormick-exact given xbar_s >= x~_s (xbar_s = w_max times a flow bound, here the demand vector). RLT form: if y_j = 1 then u_j = w, v_j = u and z_sj ranges over the scaled recourse polyhedron while x~_s - z_sj is a recession direction with c^T(x~_s - z_sj) >= 0 (dual feasibility), so min nu_sj c^T z_sj = nu_sj w Q_s(y); if y_j = 0 then u_j = 0, v_j = 0 and z_sj is a recession direction with c^T z_sj >= 0, minimum 0 = y_j (.). Verified: both forms give |value(y) - F(y)| = 2.8e-14 at all binary y and MILP optimum = 53.8404, 55.7492, 60.5684 = enumeration.
- **(derived) Relaxation quality (numbers).** RLT form: 50.206 (6.75 %), 51.885 (6.93 %), 56.025 (7.50 %). McCormick-on-x~ form as stated: 24.558 (54.4 %), 25.232 (54.7 %), 27.374 (54.8 %): the bound xbar_s = w_max d_s acts exactly like a big-M on Q. Naive McCormick on the same logit model (p_s = nu_s0 w + nu_s^T u linear in the Charnes-Cooper variables, omega_s >= McCormick(p_s, theta_s), theta_s >= cuts in y): 52.328 (2.81 %), 54.164 (2.84 %), 57.807 (4.56 %) with U = Qmax and 2.81/2.84/4.89 % with U = 10 Qmax. Candidate 3 is therefore *not* tighter than naive McCormick on these instances, even in its bound-free variant.
- **(derived) Mechanism.** At the RLT relaxation optimum of S4, y = (0.351, 0.186, 0.351) but w = 0.1001 while 1/D(y) = 0.1375, and u = (0.057, 0.047, 0.057) while y w = (0.035, 0.019, 0.035): the scaled recourse operates at capacity ratio u/w = (0.57, 0.46, 0.57), i.e. "more open" than y, while the numerators N_s(y) stay at the fractional y. Only the normalization and the McCormick boxes link (w, u) to y, and with w ranging over [1/15.2, 1/4] = [0.066, 0.25] those boxes are loose. The naive baseline avoids this because its recourse cost theta_s is tied to y directly and only the probabilities pass through (w, u).
- **(derived) Benders combination.** The scaled recourse has the same dual polyhedron, so the cut family is the same: eta_s0 >= alpha_k^T d_s w - g_k^T u and eta_sj >= alpha_k^T d_s u_j - g_k^T v_j. Converges in 2-3 iterations but to a weaker bound (42.35 = 21.3 % gap on S4, 21.5 % on S8, 22.3 % on S6/seed 2) than the explicit RLT LP (6.75-7.50 %), because scenario-wise cuts drop the coupling x~_s - z_sj between the two product copies. Recovering the LP bound by cuts requires separating on the joint two-copy polyhedron per (s, j) (an LP with 2 m_x variables), not on Q_s alone.
- **(derived) Size.** 1 + n + n(n - 1)/2 + n(n - 1)/2 + S m_x + S n m_x continuous variables (only j with nu_sj != 0 need z_sj); rows: 4n (u) + 1 (normalization) + 3 n(n - 1)/2 (Y) + 4 n(n - 1)/2 (v) + S(m_A + m_B) + S n (2 m_A + 2 m_B + 2 m_x) [RLT] or 4 S n m_x [McCormick]. Requires one common denominator D(y) (single segment, or one w per segment with segment-separable recourse).

### Gaps
- No valid inequality was found that re-couples w to y beyond the McCormick boxes while keeping linearity; a tighter hull of {(w, u, y): w = 1/D(y), u = y w, y binary} is the known 0-1 hyperbolic-programming question (Ahmed 2000 convex extension, not accessible per `change_of_measure.md`).

## Q4. Candidate 4 (Hammer-Rubin convexification with rho = 2 sum_s ||a_s|| L_s)

### Takeaway
The weak-convexity modulus is correct for affine p_s >= 0 on the box and piecewise-linear convex L_s-Lipschitz Q_s (proof by restriction to lines; the only subtlety is that kinks of Q_s add nonnegative derivative jumps, so no extra modulus is needed), and the convexified MINLP is exact with a valid convex relaxation; numerically the convexified G had zero midpoint-convexity violation on 1500 random pairs per instance. But the bound is useless: 52.9 %, 41.8 %, 38.3 % gaps versus ~2 % for McCormick and 0 % for RLT-1, because the shift (rho/2)(||y||^2 - 1^T y) is as low as -rho n/8 = -32 to -38 at the centre of the box, 60 % of the optimal value. The modulus formula does not extend to multilinear p (counterexample below).

### Cited Findings
- Hammer & Rubin, "Some remarks on quadratic programming with 0-1 variables", RAIRO 4(3) (1970) 67-79, [Numdam](http://www.numdam.org/item/M2AN_1970__4_3_67_0/) (cited, not re-fetched); best diagonal convexification via SDP — Billionnet & Elloumi, Math. Program. 109 (2007) 55-68, [DOI 10.1007/s10107-005-0637-9](https://doi.org/10.1007/s10107-005-0637-9) (cited, not re-fetched).
- Weak-convexity statement and modulus as proposed — `mdp_rl_ideas.md` KQ2 ("treat as my derivation") and the Miller et al. mixture-dominance remark "2 eps beta-weakly convex at best" in `mdp_rl_ideas.md` KQ4.

### Inferences
- **(derived) Statement.** p_s(y) = a_s^T y + b_s >= 0 on {0,1}^n (hence on [0,1]^n by affinity), Q_s convex PL with ||g_k|| <= L_s for all its pieces; G(y) = f^T y + F(y) + (rho/2)(||y||^2 - 1^T y), rho >= sum_s 2 ||a_s|| L_s. Claim: G convex on the box and G = f^T y + F on {0,1}^n.
- **(derived) Proof of the modulus (nonsmooth case).** Fix a line y(t) = y0 + t v, ||v|| = 1, inside the box. phi_s(t) = p_s(t) Q_s(t) with p_s(t) = p0 + (a_s^T v) t affine and Q_s(t) = max_k (m_k t + c_k), m_k = g_k^T v in [-L_s, L_s]. On each linear piece phi_s'' = 2 (a_s^T v) m_k >= -2 ||a_s|| L_s. At a kink of Q_s where the slope jumps from m_1 to m_2 > m_1, the one-sided derivatives of phi_s are (a_s^T v) Q_s(t) + p_s(t) m_{1,2}, so the derivative jumps by p_s(t)(m_2 - m_1) >= 0 because p_s >= 0: kinks are convex. Hence phi_s + (rho_s/2) t^2 has nondecreasing derivative for rho_s = 2 ||a_s|| L_s, i.e. is convex, and summing over s, F + (rho/2)||y||^2 is convex on every line in the box, hence on the box. The sharper per-piece modulus is max_k (||a_s|| ||g_k|| - a_s^T g_k) (eigenvalues of a g^T + g a^T are a^T g +/- ||a|| ||g||), attained only when g_k is antiparallel to a_s. Exactness on binaries: y_j^2 = y_j. Numerically: with rho = 101.0 (S4), 86.6 (S8), 90.9 (S6/seed 2) (L_s = max over dual vertices of ||U^T beta_k|| = 139.3, equal to the crude bound penalty x ||cap|| here), max midpoint violation of G over 1500 random pairs = 0.0 on all instances. A sampled lower estimate of the true modulus of F (8 (F(mid) - avg)/||y1 - y2||^2 over 3000 pairs) is 31.4, 24.8, 22.4, so the claimed rho is at least 3x conservative; using the sampled estimate as rho left a violation of 1.3e-2 on S6/seed 2, so the sampled value is strictly below the true modulus.
- **(derived) The bound is trivially loose.** The convex relaxation value is <= G(1/2 1) = f^T 1/2 + F(1/2 1) - rho n/8; rho n/8 = 37.9, 32.5, 34.1 here against optimal values 54-61. Measured: min_box G = 25.54 (gap 52.9 %), 32.67 (41.8 %), 37.70 (38.3 %), attained at interior points (0.69, 0.51, 0.60) etc. With the (invalid, too small) sampled modulus the gaps are 13.2 %, 9.9 %, 6.3 %. McCormick MC-B: 1.98 %, 1.77 %, 1.96 %; per-factor C2: 1.96 %, 1.54 %, 0.97 %; RLT-1 LP: 0 %. For reference, min of F itself over a 6^3 grid of the box is within 1.4 % of the binary optimum on all instances, so almost the entire gap is manufactured by the convexifying shift.
- **(derived) Counterexample for multilinear p.** If p_s(y) = y_1 y_2 and Q_s = M constant (L_s = 0), the claimed modulus is 0 but the Hessian of M y_1 y_2 is M [[0, 1], [1, 0]] with eigenvalue -M: the true modulus is M = max Q, so for multilinear p the modulus scales with the recourse cost level, not with its Lipschitz constant. The formula is affine-only.
- **(derived) Benders/OA combination.** G is convex nonsmooth; subgradient grad G(y) = f + sum_s [a_s Q_s(y) - p_s(y) U^T beta_s(y)] + rho(y - 1/2 1) needs one LP per scenario, and Kelley/OA cuts eta >= G(y^k) + grad G(y^k)^T (y - y^k) are globally valid (converged in all runs). So it combines with scenario decomposition, but each cut is a Benders cut "shifted" by the score term a_s Q_s and by rho(y - 1/2), and the master bound inherits the looseness above. Variables: n + 1 (plus K OA cuts). Improving rho by a diagonal shift vector (Billionnet-Elloumi style) would need an SDP-type certificate for a non-quadratic F; not available.

### Gaps
- The exact weak-convexity modulus of F (as opposed to the sum of per-scenario, per-piece bounds) was not computed; the sampled estimate brackets it in [31.4, 101] for S4.

## Q5. Combinations of the candidates

### Takeaway
Candidate 1 + Benders is natural and value-preserving (cuts on the scaled recourse are the same dual vertices; verified equal bounds). Candidate 2 + Candidate 3 (multiplied cuts in the monomial x w space) gives an exact bound-free MILP for Gibbs or logit probabilities (verified exact; 10.8-17.2 % gaps for Gibbs, between naive McCormick 3.6-7.1 % and Candidate 1 33-42 %). Adding Candidate 1's KL constraint, rewritten linearly in the lifted monomial x w variables, to that master changed nothing (identical bounds to four decimals) on all instances. Candidate 4 does not combine usefully with anything because its looseness is intrinsic to the shift.

### Cited Findings
- Cut-and-project / extended-space cuts dominate master-space cuts — [Bodur et al. 2017](https://ideas.repec.org/a/inm/orijoc/v29y2017i1p77-91.html) (via `global_opt_submodularity.md` Q9).
- Exact binary expansion exp(sum_i a_i T(s) y_i) = prod_i (1 + (e^{a_i T(s)} - 1) y_i) on {0,1}^n — `change_of_measure.md` Q1 (derived there).

### Inferences
- **(derived) Candidate 1 as the "r-variable" version of Candidate 2.** With Benders cuts, Candidate 1's master is linear in (eta, r, w): eta_s >= (alpha_k^T d_s) r_s - g_k^T w_s. For affine p this is Candidate 2 after substituting r = p(y), w_sj = b_s y_j + sum_l a_sl Y_lj. The two differ only in how (r, w) are tied to y: by the Boolean-quadric lift (exact linear description at binary points, Candidate 2) or by the KL constraint plus McCormick (Candidate 1). So "combining the lifted monomial space with the r-variables" is not a new formulation; r is redundant whenever p is polynomial in y.
- **(derived) Candidates 2 + 3 for Gibbs p.** p_s(y) = q_s e^{-beta b_s} M_s(y) w with M_s(y) = sum_M m_sM z_M multilinear (binary expansion), w = 1/Z(y), v_M = z_M w; lifted cuts eta_s >= q_s e^{-beta b_s} sum_M m_sM [alpha_k^T d_s v_M - sum_l g_kl v_{M u {l}}] with v_{M u {l}} = v_M if l in M. Exact at binary y (2.8e-14), MILP = enumeration on all instances; relaxation gaps 17.2 % (S4), 10.8 % (S8), 13.1 % (S6/seed 2) versus naive McCormick 4.0/3.6/7.1 % and Candidate 1 33/34/42 %. Weaker than naive McCormick for the same reason as whole-p Candidate 2 (mixed signs of m_sM); the per-factor repair here is the full Lagrange expansion, i.e. enumeration. Size: 2^n monomials (or the monomials of the support of a_s), 2^n v-variables, 4 McCormick rows each, one normalization row.
- **(derived) Candidate 1's KL constraint inside Candidate 2's master.** In the lifted (v, y) space r_s = q_s e^{-beta b_s} sum_M m_sM v_M and r_s y_j = q_s e^{-beta b_s} sum_M m_sM v_{M u {j}} are both linear, so KL(r(v)||q) + beta sum_s (a_s^T (r y)(v) + b_s r_s(v)) + log Z(y) <= 0 is a valid convex exponential-cone constraint (equality at binary points). Added to the Candidate 2+3 master (solved with CLARABEL) it left the bound unchanged: 46.6226, 51.9316, 55.8967 with and without. The lifted point already satisfies it with slack; the KL identity carries no information that the normalization sum_s r_s(v) = 1 and the monomial lift do not already carry.
- **(derived) Ranking on the toy instances (continuous-relaxation gap, best valid variant of each).** Affine: RLT-1 LP 0 % < per-factor C2 1.0-2.0 % <= MC-B 1.8-2.0 % (tight U), 2.6-4.7 % (10 U) ~ whole-p C2 1.8-5.0 % < C4 38-53 %. Gibbs: naive McCormick 3.6-7.1 % < C2+3 10.8-17.2 % < C1 33-42 %. Logit: naive McCormick 2.8-4.9 % < C3 (RLT) 6.8-7.5 % << C3 (McCormick on x~) 54-55 %. The only candidates that *beat* naive McCormick are the per-factor/RLT versions of Candidate 2 (affine p), and they do so without any bound on Q_s.

### Gaps
- All rankings are for n = 3; the relative advantage of RLT-type lifts over McCormick typically grows with n (McCormick's error per product is O(U - L)/2 at y_j = 1/2 while the hull is bound-free), but this was not measured.
- No run with p_s having both positive and negative coefficients in a *multilinear* (degree >= 2) polynomial model was done, so the size/tightness trade-off of the posiform repair at degree 2 is unmeasured.
