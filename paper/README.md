# White paper

`main.tex` is the working paper; `main.pdf` is its build. Compile with tectonic (installed via brew; it fetches
packages on demand):

    tectonic main.tex

Numbers in the tables come from `experiments/RESULTS.md` and the CSVs under `experiments/`. The Claude Docs version of the same text is at https://claude.ai/artifact/AmffrLp4xPgnGwrYJvUpDK.
